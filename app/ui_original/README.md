Original Skin backup created for Milestone 5.5.

This folder is a permanent snapshot of the SafeSend UI layer before the New Skin theme architecture was introduced. It preserves the previous layouts, styles, and screen modules so the application can be reverted or compared later without relying on source control history.

The live application imports from `app/ui`. The New Skin is controlled through `app/ui/theme.py`; the Original Skin palette is also defined there for future runtime skin switching.
